DevOps Troubleshooting & Diagnostic Suite

Key Linux & Docker commands for monitoring and debugging issues during deployment.

🐳

Docker Container Diagnostics

  • docker ps
    List active running containers on EC2
  • docker logs portfolio
    Inspect stdout/stderr output from Nginx
  • docker inspect portfolio
    View container network & port bindings
🐧

Linux Server Health

  • systemctl status docker
    Check if Docker daemon is active and running
  • df -h && free -h
    Check disk space and RAM usage on EC2
  • ss -tulpn | grep 80
    Verify Port 80 listener status
🛠️

Manual Deployment Fallback

  • docker pull <username>/automated-cicd-portfolio:latest
    Manually pull fresh image from Docker Hub
  • docker stop portfolio && docker rm portfolio
    Clean up outdated existing container
  • docker run -d -p 80:80 --name portfolio ...
    Launch container attached to HTTP Port 80
